The site uses extensionless production URLs, but app.js previously compared location.pathname
against keys ending in .html. On clean URLs, this prevented intended dynamic CTA blocks from
running on several high-intent comparison pages. The patch normalizes both forms.

CONVERSION FINDING
The Housecall Pro referral landing page currently headlines a special 20% discount for the
first 12 months. Existing site CTAs focused only on the free trial. The patch uses
"See Current Housecall Pro Offer" and adds a dated, cautious offer note on the dedicated review.

SEO / UX FINDING
Finder and calculator JavaScript generated .html internal links even though canonical URLs are
extensionless. The patch outputs clean internal URLs to avoid extra redirect hops.
